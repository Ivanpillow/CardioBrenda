02 — Skill files

design-taste Stable

Anti-Slop Frontend

Lee el brief antes de generar código. Infiere la dirección de diseño correcta. Bloquea todos los patrones predecibles que hacen que las interfaces se vean iguales.

  • Tres locks irrompibles: color, shape y page theme
  • Hero discipline: viewport-fit garantizado
  • Sistema de diales: variance, motion, density
  • Dark mode con paridad de jerarquía WCAG AA
  • Ban list de 16 patrones anti-slop
  • Protocolo de rediseño para proyectos existentes
  • Pre-flight checklist obligatorio antes de entregar
npx skills add Leonxlnx/taste-skill
design-motion Craft

Ingeniería de Interfaces

Filosofía de Emil Kowalski aplicada. Cada detalle se acumula en algo que se siente correcto. Modos BUILD y AUDIT para crear o revisar motion en interfaces existentes.

  • Animation Decision Framework por frecuencia y propósito
  • Curvas easing personalizadas (no CSS defaults)
  • Patrones canónicos: button press, popovers, tooltips
  • Gestos con momentum, boundary damping y friction
  • CSS transform mastery (sin layout reflow)
  • Accesibilidad completa: prefers-reduced-motion
  • Anti-slop checklist con severity levels
npx skills add emilkowalski/skill
